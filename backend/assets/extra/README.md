# assets/extra

都営以外の事業者の ODPT データ（都内に絞ったもの）を置くディレクトリ。

公共交通オープンデータ基本ライセンス・チャレンジ限定ライセンスは、データと派生データ（gob を含む）を
第三者が再利用できる状態で公開することを禁じている。このリポジトリは公開なので、ここには
この README 以外をコミットしない（`.gitignore` で除外している）。

- 手元: `backend/.env` にキーを書き、`scripts/update_assets.sh` を実行すると、ここにデータができる
- 本番: CD が非公開の S3 から取ってきて埋め込む

データが無ければ、アプリは都営だけで動く。設計は `docs/design/multi-operator.md` 4章。
